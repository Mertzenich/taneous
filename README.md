# Taneous

ClojureScript wrapper for the [InstantDB](https://www.instantdb.com) [backend SDK](https://www.instantdb.com/docs/backend).

This project is a **work-in-progress**.

## Development

``` shell
shadow-cljs watch app
node target/core.js
```

## Testing

``` shell
shadow-cljs compile test
```
